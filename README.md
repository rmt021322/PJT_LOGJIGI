# 로그지기 LOGJIGI 초안

‘내 블로그에 AI 비서가 살면 어떨까?’라는 생각에서 시작한 개인 프로젝트입니다.

이 브랜치는 캐릭터와 대화창을 배치하며 웹 화면을 구상하던 초기 작업을 보관합니다. 아래 이미지는 당시의 화면 제작 기록입니다.

**현재 기능과 실행 방법은 [prototype 브랜치](https://github.com/rmt021322/PJT_Logjigi/tree/prototype)에서 확인할 수 있습니다.**

## 이후 발전 방향

초기 화면 구상을 바탕으로 블로그 ID 입력, 공개글 검색, 크롤링 기능을 추가하며 프로토타입으로 발전시켰습니다.
